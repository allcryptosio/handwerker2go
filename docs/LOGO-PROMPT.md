# Logo-Prompts für handwerker2go

Markenfarben aus der Website: Waldgrün #12704F, Dunkelgrün #0B2E1F, Mint #EAF5EE.
Am besten mit einem Generator, der Text gut beherrscht (z. B. Ideogram, Recraft, GPT-Image, Midjourney v7).
Danach als SVG nachbauen bzw. vektorisieren lassen.

## 1. Hauptlogo (Bildmarke + Schriftzug)

```
Minimal flat vector logo for "handwerker2go", an eco-friendly online marketplace for local craftsmen.
Icon: a simple house outline whose roof line turns into a single leaf, with a small wrench subtly forming
the leaf's stem, drawn with one continuous geometric line of even stroke width, rounded line ends.
Wordmark to the right: "handwerker" in a clean, modern geometric sans-serif (similar to Inter or Manrope, bold),
lowercase, deep forest green #12704F, followed by "2go" in white inside a rounded green pill #12704F.
Flat colors only, no gradients, no shadows, no 3D, no mockup, no extra text, plain white background,
lots of negative space, balanced and legible at small sizes, professional, friendly, sustainable feel.
```

## 2. App-Icon / Favicon (nur Bildmarke)

```
Minimal app icon for an eco-friendly craftsman marketplace: a white geometric house outline with a leaf
forming the roof, centered on a rounded square in forest green #12704F. Single even stroke weight,
rounded corners, flat vector, no text, no gradient, no shadow, highly legible at 32x32 pixels.
```

## 3. Variante „Blatt-Werkzeug“

```
Minimalist logo mark: a green leaf whose central vein is shaped like a screwdriver, combined with the
lowercase wordmark "handwerker2go" in a modern rounded sans-serif, colors forest green #12704F and
dark green #0B2E1F on white, flat vector style, simple, timeless, eco-friendly, no gradients, no clutter.
```

## Was vermeiden (bei Midjourney als `--no`, sonst ans Ende hängen)

```
--no gradient, shadow, 3d, photorealistic, glossy, clipart, multiple logos, mockup, extra words, watermark
```

## Danach

- 3 bis 4 Varianten erzeugen, die beste auswählen.
- Als SVG an Claude geben: Logo, Favicon und App-Icon werden eingebaut, die Textmarke im Header wird ersetzt.
- Markenrecht: Vor Nutzung kurz prüfen, ob es ein ähnliches eingetragenes Logo gibt (DPMA/EUIPO-Suche).
